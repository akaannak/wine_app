# Ответ на 4.5 
st.cache_resource используется для модели, потому что это один общий объект, который нужно загрузить один раз и повторно использовать при перезапусках Streamlit.

st.cache_data используется для таблицы и вероятностей, потому что это данные и результаты вычислений.

Если вызывать joblib.load без декоратора, модель будет загружаться с диска при каждом перезапуске скрипта, например при движении слайдера и это увеличит время загрузки приложения.

# Инструкция как запустить приложение 
### Требования:
- Python 3.15.0
- библиотеки из requirements.txt
### Запуск
1. Откройте терминал в папке wine_app.
2. Создайте виртуальное окружение:
python3 -m venv .venv
3. Активируйте его:
source .venv/bin/activate
4. Установите зависимости:
python -m pip install -r requirements.txt
5. Запустите приложение:
python -m streamlit run app.py
6. Откройте в браузере http://localhost:8501.
